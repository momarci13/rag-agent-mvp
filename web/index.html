            Privacy and terms of use

            This is a self-hosted tool. It has no user accounts, sells nothing and runs no analytics.

            What data leaves this machine

            • OpenAI API: the brief, a summary of each data table (column names, types, statistics and 5 sample rows), passages from library documents, generated code and test output. OpenAI's terms and data policy apply to that traffic.
            • Nothing else. Generated model code runs locally with no API keys in its environment. The full datasets are read only by that local code.

            What is stored

            • Projects, uploaded data, generated code, test results and documents are saved under output/studio/ on the server.
            • Documents you attach are copied into the shared library (output/library/) and indexed so later projects can cite them.
            • Names and roles entered at sign-off are written into the validation report and the project record.

            Cookies and browser storage

            The app sets no cookies and loads no third-party scripts, fonts or trackers. Your browser keeps the theme, sidebar state and last page in local storage, and the API token in session storage for the current tab only. These are needed for the interface to work, so no consent banner is required.

            Terms of use

            • Models, code, tests and documents are produced by language models and can be wrong. A qualified developer and an independent validator must review them.
            • The validation outcome is a rule-based summary of findings, not an approval. Only the recorded human sign-off is a decision, and it remains your institution's responsibility.
            • Built-in regulatory summaries are not the legal texts. Attach official texts for anything you rely on.
            • Nothing here is investment advice. Backtests are hypothetical.
            • Generated code runs on this machine with your user's permissions. Run the server in an environment you are comfortable executing untrusted code in.
            • Upload only data and documents you are allowed to process and to send (in summary form) to OpenAI.

            Your rights under GDPR

            If the data you upload contains personal data, you are the controller. Prefer pseudonymised data. People can ask you to see, correct or delete records under output/ that concern them. Add your contact details here before sharing the app.
